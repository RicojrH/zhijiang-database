    本项目由 @没品人类之一 搭建，面向二创剪辑师与粉丝提供直播回放台词与名场面快速检索。 字幕数据定期更新（主要看我什么时候有时间更新，一般不会超过三天）。 如果你在使用过程中发现识别错词、功能 Bug、场景标签误差，或有新的热梗词条与功能建议，非常欢迎通过 B 站私信 / 评论或 GitHub Issue 反馈交流！

    程序源码、纠错词表与前后端架构均已开源（2 GB 级完整 SQLite 语料文件体量较大，托管于云端只读接口，不包含在 Git 代码仓库内）。 所有字幕来自 B 站公开直播回放自带 AI 字幕与本地语音识别补录，点击链接直达 B 站原视频，版权归原作者及对应版权方所有。
